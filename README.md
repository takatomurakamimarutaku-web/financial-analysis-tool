# 財務分析ツール

iPhone のブラウザで使える財務分析ツールです。HTML / CSS / JavaScript のみで作成しており、ビルドや外部ライブラリは使っていません。

- 金額単位：千円
- データはこの端末のブラウザ（localStorage）にのみ保存し、外部へは送信しません
- 計算結果の丸めは表示時のみ行い、内部では丸めません

## 機能

### Phase 1：単一期の財務指標計算

- PL 8項目・BS 11項目を入力すると、20指標を即時に再計算してカテゴリ別に表示
- 各指標をタップすると「計算式」と「一般的な見方」を展開
- サンプルデータ読込 ／ クリア ／ 結果をテキストでコピー
- 貸借の不一致チェック（差額を表示）、債務超過の警告
- 入力内容は自動保存（次回開いたときに復元）

### Phase 2：複数期比較（最大5期）

- 「入力」タブ：期の追加（期名は「2025/3期」→「2026/3期」のように自動提案）・削除・並べ替え（←→）・期名の編集。左が古い期です
- 「比較」タブ：行＝指標、列＝各期の比較表。前期比（増減額・増減率）を表示（非表示にも切替可）
  - スマホでは横スクロールでき、指標名の列は固定表示
- 主要指標（売上高・営業利益・EBITDA・営業利益率・自己資本比率）の推移グラフ（SVG で自作、外部ライブラリなし）
- 期末残高ベース／平均残高ベースの切り替え
- サンプルデータは 2023/3期〜2025/3期 の3期分（2025/3期は Phase 1 のサンプルと同じ数値）

#### 前期比の計算

| 項目 | 計算 | 表示 |
| --- | --- | --- |
| 増減額 | 当期 − 前期 | % の指標はポイント（pt）、その他は各単位 |
| 増減率 | (当期 − 前期) ÷ 前期 | 前期が 0 →「—」、前期がマイナス →「参考外」、どちらか未入力 →「—」 |

「前期」は比較表で1つ左の列の期です。

#### 平均残高ベース

- 平均残高 = (前期末 + 当期末) ÷ 2
- 対象：ROA、ROE、売上債権回転日数、棚卸資産回転日数、仕入債務回転日数、CCC（比較表で★印）
- 前期データがない期（先頭の期）は「—」
- 平均自己資本がマイナスの場合、ROE は「参考外」
- 対象外の指標は期末残高で計算します

### 入力のしかた

- カンマ・全角数字も入力できます（例：`１，２３４` → 1,234）
- マイナスは「±」ボタンで符号を反転します（iPhone の数字キーボードにマイナス記号がないため）。貼り付けの場合は `-500`、`△500`、`▲500` も負数として扱います
- 空欄は「未入力」として扱い、0 とはみなしません

## 計算式一覧（期末残高ベース）

| カテゴリ | 指標 | 計算式 | 表示 |
| --- | --- | --- | --- |
| 収益性 | 売上総利益率 | (売上高 − 売上原価) ÷ 売上高 | % |
| 収益性 | 営業利益率 | 営業利益 ÷ 売上高 | % |
| 収益性 | 経常利益率 | 経常利益 ÷ 売上高 | % |
| 収益性 | ROA | 経常利益 ÷ 総資産 | % |
| 収益性 | ROE | 当期純利益 ÷ 自己資本 | % |
| 安全性 | 流動比率 | 流動資産 ÷ 流動負債 | % |
| 安全性 | 当座比率 | (現預金 + 売上債権) ÷ 流動負債 | % |
| 安全性 | 自己資本比率 | 自己資本 ÷ 総資産 | % |
| 安全性 | 固定比率 | 固定資産 ÷ 自己資本 | % |
| 安全性 | 固定長期適合率 | 固定資産 ÷ (自己資本 + 固定負債) | % |
| 安全性 | D/Eレシオ | 有利子負債 ÷ 自己資本 | 倍 |
| 安全性 | インタレスト・カバレッジ・レシオ | 営業利益 ÷ 支払利息 | 倍 |
| 効率性 | 総資産回転率 | 売上高 ÷ 総資産 | 回 |
| 効率性 | 売上債権回転日数 | 売上債権 ÷ 売上高 × 365 | 日 |
| 効率性 | 棚卸資産回転日数 | 棚卸資産 ÷ 売上原価 × 365 | 日 |
| 効率性 | 仕入債務回転日数 | 仕入債務 ÷ 売上原価 × 365 | 日 |
| 効率性 | CCC | 売上債権回転日数 + 棚卸資産回転日数 − 仕入債務回転日数 | 日 |
| M&A | EBITDA | 営業利益 + 減価償却費 | 千円 |
| M&A | ネットデット | 有利子負債 − 現預金 | 千円 |
| M&A | ネットデット ÷ EBITDA | ネットデット ÷ EBITDA | 倍 |

表示桁数：% と日は小数1桁、倍と回は小数2桁、千円は整数。

### 計算できない場合の表示

| 表示 | 条件 |
| --- | --- |
| — | 分母が 0、または計算に必要な項目が未入力 |
| 参考外 | 債務超過（純資産 < 0）のときの ROE・D/Eレシオ・固定比率 |
| 参考外 | 固定長期適合率で、自己資本 + 固定負債 < 0 |
| 参考外 | ネットデット ÷ EBITDA で、EBITDA < 0 |

自己資本比率は債務超過でもマイナス値のまま表示します。赤字の利益率・ICR、ネットキャッシュ（ネットデットがマイナス）もマイナス値で表示します。

### チェック

- 総資産 ≠ 流動資産 + 固定資産 → 差額を表示して警告
- 総資産 ≠ 流動負債 + 固定負債 + 純資産 → 差額を表示して警告
- 差額の絶対値が 0.0005千円（0.5円）未満は一致とみなします（小数計算の誤差対策）
- 必要な項目が未入力の間は判定しません

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | 画面 |
| css/style.css | スタイル（スマホ優先） |
| js/calc.js | 指標計算（DOM に依存しない純粋関数）。入力項目・指標の定義もここ |
| js/store.js | データ保存・読込（localStorage）、データ形式の正規化・バージョン確認、期の追加・削除・並べ替え |
| js/chart.js | SVG 折れ線グラフの生成（DOM に依存しない純粋関数） |
| js/ui.js | 画面描画・イベント処理 |
| test/*.test.js | テスト（`node --test`） |

### データ形式（version 1）

```json
{
  "version": 1,
  "companyName": "",
  "periods": [
    { "label": "2025/3期", "pl": { "sales": null, "...": null }, "bs": { "cash": null, "...": null },
      "adjustments": [], "debtLikeItems": [] }
  ]
}
```

localStorage のキーは `finAnalysisTool.data` です。

## テスト

Node.js 18 以上で実行できます（依存パッケージなし）。

```sh
node --test
```

## ローカルでの確認

ES Modules を使っているため、`index.html` をダブルクリックで開く（file://）と動きません。簡易サーバーを起動して開いてください。

```sh
python3 -m http.server 8000
# または: npx serve .
```

ブラウザで http://localhost:8000/ を開きます。

## GitHub Pages での公開手順

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch を `main`、フォルダを `/ (root)` にして **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
5. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使える

注意：保存データは端末・ブラウザごとに別です。Safari の「履歴とWebサイトデータを消去」を行うとデータも消えます。
